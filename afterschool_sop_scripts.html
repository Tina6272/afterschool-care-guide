課後照顧班：具體話術與SOP流程完整手冊

整合特教實務、正向行為支持與情緒緩降策略，供課後照顧班教師現場參考使用

普通生常見情境：具體話術與應對流程

📝

情境一：不願意寫作業

最常見，原因多樣
1
先觀察，不立即施壓
給孩子1至2分鐘，觀察是真的不知如何開始，還是在發呆、玩東西
2
靠近輕聲詢問
✓ 建議說法
「你今天有幾樣作業？我們來看一下，先從最簡單的開始，好嗎？」
✗ 避免說法
「你為什麼還沒開始寫？」「大家都在寫了，只有你沒寫！」
3
五分鐘啟動法
✓ 建議說法
「我們只要先寫五分鐘就好，不用全部。你寫，老師也在旁邊陪你。」
4
仍不動筆：了解原因
→ 進一步詢問
「這題你不會嗎？還是你今天不想寫？告訴老師，我們一起想辦法。」
→ 不會：先做示範題；心情不好：同理後給彈性；若長期如此，記錄並告知導師
⚠ 若每天都不寫：填寫「作業輔導記錄表」，學期累積3次通知家長；持續5次通報導師協同處理。
🤝

情境二：同學衝突吵架

打架、言語衝突、告狀
1
立即分開，各自冷靜
→ 立即說法（堅定但平靜）
「先停下來。A，你先去那邊坐；B，你在這邊。我們等一下再說。」
2
分別聆聽（不評判）
✓ 聆聽話術（對每個孩子分別說）
「你說說看，剛才發生了什麼事？」（只聽，不打斷，不說「但是」）
3
引導說出感受與需求
✓ 建議說法
「所以你當時是覺得__，才會__，對嗎？」
「你希望他怎麼做，你才會好過一點？」
4
雙方和解確認
✓ 建議說法
「你們兩個都說清楚了。現在各說一句，下次要怎麼做？」
📝 有肢體衝突（打人）必須填寫事件記錄並通知雙方家長，同時告知導師。
😔

情境三：孩子悶悶不樂

可能在家有狀況或在校受挫
1
輕聲靠近，不強迫說話
✓ 建議說法
「老師注意到你今天好像有點不開心，沒關係，不用現在說。如果想說的時候，老師在。」
2
給出口，不給壓力
在旁邊放張白紙，說：「你可以畫畫或寫下來，也不用給老師看。」
3
對作業有彈性
✓ 建議說法
「今天先寫你最有把握的那幾題，其他的回家再寫，好嗎？」
🚨 若孩子說出「不想活」「想消失」等字句：不要輕忽，立即冷靜回應：「謝謝你告訴我，我很擔心你。」並立即通知輔導老師，不得獨自評估或等待。
🏃

情境四：不遵守常規

亂跑、大聲喧嘩、不聽指令
1
第一次：非語言提示
眼神接觸 + 手勢（請坐下）；不用語言打斷全班。
2
第二次：靠近輕聲提醒
✓ 建議說法（靠近，低聲）
「○○，現在是寫作業的時間，請你先坐下來。」
✗ 避免說法
「你是在搗蛋嗎？！怎麼那麼不懂事？！」
3
第三次：給予選擇
→ 選擇話術
「你可以選擇：現在坐下繼續寫，或是先去冷靜區坐五分鐘。你選哪個？」
4
事後私下對話
✓ 建議說法
「剛才發生什麼事了？你願意告訴老師嗎？」（了解動機後調整策略）
😢

情境五：孩子哭泣

委屈、被欺負、思念家人
1
先讓孩子哭，不急著止哭
✓ 建議說法
「沒關係，想哭就哭，老師在這裡。」（遞紙巾，靜靜陪著）
2
等情緒稍緩再問
✓ 建議說法
「你準備好說了嗎？告訴老師，是什麼讓你這麼難過？」
✗ 避免說法
「不要哭了！這有什麼好哭的？」「趕快說，還要寫作業！」
3
反映感受，讓孩子感覺被懂
✓ 建議說法
「聽起來你很委屈，因為你覺得被誤會了，對嗎？這樣的感覺很難受。」
⭐

情境六：正向回饋時機

具體稱讚，建立動機
稱讚要「具體」才有效，避免空泛的「你好棒！」
✓ 具體稱讚範例
「你今天數學那頁的直式，算得很整齊，步驟都對了！」
「我注意到你今天一進來就開始寫，沒有拖，這很不容易！」
「你把不會的題目打勾先跳過，這是很聰明的方法！」
✗ 避免空洞稱讚
「你好棒！」「很好！」（孩子不知道自己做對了什麼）
💡 稱讚努力而非聰明：「你很認真算」比「你真聰明」更能建立成長型思維。

情緒爆發三階段：SOP流程與話術

🌡 前期：情緒上升期

孩子開始出現焦慮、煩躁、言語增多或沉默。行為有跡可循，是介入最有效的時機。

🔥 中期：情緒高峰期

完全失控、可能有攻擊行為或破壞物品。此時講道理無效，以確保安全為唯一目標。

🌿 後期：情緒緩降期

孩子開始從高峰退下，但未完全平靜。此時不宜立即要求善後，需觀察是否有第二波。

🔴 前期（上升期）：預防與穩住

觀
辨識早期訊號 臉色改變、說話變尖銳、不回應老師、眼神飄移、開始跺腳或用筆敲桌
靠
低調靠近，私下介入 不要在全班面前點名，輕聲走近
說
說話術：命名情緒 + 給出路
✓ 建議說法
「老師看你現在好像有點煩，你可以告訴我發生什麼事嗎？」
「如果你需要休息一下，可以先去喝個水，沒關係。」
減
降低刺激 移除可能引發衝突的同學或物品；暫時減少對孩子的要求（先不要求寫作業）

🔴 中期（高峰期）：安全第一

安
確保安全：疏散周圍同學
→ 對其他孩子說
「同學們先安靜繼續寫作業，老師現在去幫那個同學。」（平靜、不慌亂）
冷
老師自身保持冷靜 降低音量（不要提高聲音），放慢語速，肢體保持開放（不交叉雙臂）
說
此階段話術：只說一句
✓ 建議說法（重複即可，不要長篇）
「老師在這裡，你是安全的。」
「深呼吸，我陪著你。」
✗ 此時絕對不說
「你這樣很丟臉！」「你再這樣我就打電話給你爸媽！」「你為什麼要這樣？！」
報
有攻擊行為：立即請求支援 請其他人通報輔導組或教務處；課後班老師不需獨力處理肢體攻擊

🟢 後期（緩降期）：修復關係

等
等待30至60分鐘，讓孩子真正平靜 高峰後不要立即要求道歉或善後，給孩子恢復的空間
連
重新連結（不追究、先連結）
✓ 建議說法
「你現在好一點了嗎？」（等孩子回應）
「剛才很辛苦吧？你現在感覺怎樣？」
解
引導說出感受與觸發點（不說教）
✓ 建議說法
「你願意說說看，剛才是什麼讓你這麼難受嗎？」
善
善後（若有影響他人）
→ 引導但不強迫
「你覺得你剛才說的那句話有沒有傷到他？下次你想怎麼做？」
⚠ 必填記錄：情緒爆發事件需填寫「行為觀察記錄表」，記錄時間、觸發點、行為描述、介入方式，提供給導師與輔導組。

自閉症（ASD）：具體話術與SOP

情境一

拒絕配合課後班常規（不肯坐定、堅持自己的方式）

SOP流程

1
不當眾糾正，先靠近
ASD孩子對公開糾正極度敏感，先靠近再低聲引導
2
給具體指令，不給模糊要求
3
提供視覺化的選擇
手指著流程表：「現在是寫作業的時間（指圖），接下來是自由時間（指圖）。」
4
仍拒絕：給彈性緩衝
「你可以再給自己2分鐘，然後我們一起開始。」設計時器讓孩子看見倒數。

話術範例

✓ 建議說法
「○○，現在請把國語作業放在桌上，打開第幾頁，寫第幾題到第幾題。」（具體、分步驟）
✗ 避免說法
「你知道現在要做什麼嗎？」「大家都在寫，你也要寫啊！」
→ 改變活動時的預告話術
「還有5分鐘，作業時間就要結束了，準備要換自由時間囉。」（提早預告）
情境二

情緒崩潰（Meltdown）：突然大哭大叫或倒地

1
不強制約束，移除觸發來源移開旁邊的同學，降低環境刺激（減少噪音、光線）
2
說最少的話，保持在場
✓ 建議說法（重複，聲音要低且慢）
「老師在這裡，你是安全的。」（不問原因，不講道理）
3
等待：ASD Meltdown通常5至20分鐘自然消退不要催促、不要問「你好了嗎」，靜靜等待
4
緩降後提供感官調節工具壓力球、毯子、安靜角落；詢問：「你想要__嗎？」（給具體選項）
5
通報事後填寫觀察記錄，通知導師與家長，說明觸發原因及處理過程

亞斯伯格症（AS）：具體話術與SOP

情境一

強烈堅持自己的「規則」，與同學起衝突（如：我的位置、公不公平）

SOP流程

1
不正面否定，先承認其感受
AS孩子強調公平原則，被否定會更激動
2
給出「規則的理由」
AS孩子接受邏輯解釋，但不接受「因為我說了算」
3
私下協商，給有限選擇
4
若情緒升高，先暫停討論
「我們等一下再說，現在先各自休息。」

話術範例

✓ 建議說法
「我知道你覺得這樣不公平，你說的那個規則我聽到了。我來解釋一下為什麼今天這樣安排……」
✓ 協商話術
「今天先這樣，明天你可以選A或B，好嗎？」（提供有限但真實的選擇）
✗ 避免說法
「你太固執了！」「規定就是規定，不能說為什麼！」
情境二

說話踩到別人地雷（不知道自己得罪人）

1
事後私下引導，不當眾糾正
2
用具體情境描述對方感受
AS孩子難以自動推測他人情緒，需要具體說明
3
教替代句型（建立社交劇本）
✓ 引導話術（具體描述，不貼標籤）
「你剛才說他的畫畫得不好看，他聽了臉色有點不開心。不是你的錯，但我想讓你知道，他聽了這句話覺得難過了。」
✓ 教替代說法
「下次如果你覺得一件事不好，可以說『我個人覺得…』或者不說，只說『嗯』就好。我們來練習看看。」

ADHD：具體話術與SOP

情境一

無法專注寫作業，東摸西摸不停分心

SOP流程

1
清空桌面，只留當前作業
2
分段任務：拆成10至15分鐘小段
3
使用計時器讓孩子「看見時間」
「計時器響之前，先把這一題寫完。」
4
段落完成立即給予正向回饋
5
給合法的動態出口
「你可以幫老師把那些作業本發下去，然後回來繼續。」

話術範例

✓ 任務拆分話術
「先寫這一頁的上半部，寫完了告訴老師，我來看。」（不說「全部寫完」）
✓ 計時器話術
「這個計時器設5分鐘，響之前你試試看能寫幾題？」
✓ 完成後立即回饋
「哇，你這5分鐘寫了3題！你自己知道嗎，你剛剛很專心！」
✗ 避免說法
「你能不能專心一下？！」「你故意的對不對？」
情境二

衝動行為：插嘴、搶東西、推撞同學

1
第一次：非語言提示（手勢+眼神）
2
事發當下：簡短且平靜地說明
3
不長篇說教，等孩子平靜後再引導
4
事後教「停、想、說、做」策略
→ 當下介入（簡短）
「○○，停。那是他的東西，請放回去。」（不問為什麼，直接說行為要求）
✓ 事後引導（平靜時）
「剛才你拿他的橡皮擦，你知道他不開心了嗎？下次你想用，可以怎麼問他？我們來說說看。」
✓ 教「停、想、說、做」
「下次你很想做一件事的時候，先停一下，想想這樣好嗎，再說出來，最後才做。我們一起練習：如果你想用他的橡皮擦，你說什麼？」

情緒行為障礙（EBD）：具體話術與SOP

情境一

情緒突然爆發：大叫、摔東西、罵人

保
立刻確保全班安全請其他孩子繼續寫作業，不要圍觀；移除危險物品
穩
老師自己先穩住（3秒深呼吸）
✓ 說最少的話
「老師在這裡。」（低聲，不說其他）
離
若孩子有物理安全需求：引導至緩和空間「你可以去那個角落坐一下，老師等你。」
報
若有攻擊行為：請求支援，通報輔導組課後班老師不需獨力處置肢體攻擊
後
情緒穩定後（不立即）：引導反思
✓ 建議說法
「你現在好一點了嗎？你願意告訴我剛才發生什麼事嗎？」
🚨 若孩子說出自傷相關言語：不要獨自評估，立即冷靜說「謝謝你告訴我，我很擔心你」，並立刻通知輔導老師。
情境二

長期拒絕參與、封閉自己

1
降低期待，先求「在場」
不強求寫作業，只要孩子在班上不引發衝突
2
每天一次短暫的非正式連結
3
從孩子的興趣切入
4
記錄並轉介輔導老師
✓ 非正式連結話術（不提作業）
「你今天帶這個來嗎？這是什麼？」（從孩子的物品或興趣切入）
「你喜歡這個嗎？你可以告訴我更多嗎？」
✓ 邀請（不強迫）參與
「這題不難，要不要試試看第一格？只有第一格就好。」
📝 若孩子封閉超過一週且無法連結，填寫觀察記錄，請輔導老師介入。

學習障礙（LD）：具體話術與SOP

情境一

作業寫不出來：閱讀困難、書寫困難、計算困難

SOP流程（依困難類型）

識
先辨識是哪種困難
閱讀跳行？寫字太慢？抄不正確？計算步驟亂？
調
調整輸入方式（老師念題目）
拆
工作分析：拆成更小步驟
替
提供替代方式完成
口頭回答→老師代為抄寫；電腦打字替代手寫
讚
完成任何部分立即具體稱讚

話術範例

✓ 調整輸入（老師念題）
「這題我念給你聽，你告訴我答案是什麼，老師幫你寫上去，好嗎？」
✓ 拆步驟（數學）
「我們先只做第一步：把這個數字寫在這裡。寫好了嗎？好，第二步……」
✓ 重建信心（關鍵話術）
「你用不一樣的方法在學習，這不是因為你不努力，是因為你的大腦需要不一樣的步驟，這樣很正常。」
✗ 避免說法
「這麼簡單你都不會？」「你剛才有沒有認真？」
情境二

「習得無助」：我不會、我不想寫、反正我就是很笨

1
不反駁、先同理
2
找到孩子「能做到」的最小單位
3
讓孩子「成功經驗」先發生
4
用「今天的你」vs「上週的你」比較
✓ 同理話術
「我知道，這個對你來說真的很難。你願意試試看一題就好嗎？就這一題。」
✓ 重新框架（不比較別人）
「你上週連第一步都不知道怎麼開始，今天你已經知道要先把數字寫在這裡了。這就是進步。」
✓ 當孩子說「我很笨」
「不是笨，是你的學習方法需要調整。老師陪你找方法，你負責努力試試看，好嗎？」

危機事件通報SOP流程

🔴 第一類：孩子出現自傷言語或行為

1
保持冷靜，立即回應（不要假裝沒聽到）
✓ 立即說法
「謝謝你告訴我，我很擔心你，我們去找一個地方說說話。」
✗ 絕對不說
「你只是說說的吧？」「不要想這些，快去寫作業。」
2
帶離現場，到安全空間避免在全班面前繼續對話
3
立即通知輔導老師課後班老師不進行風險評估，評估由輔導老師執行
4
由輔導老師通知家長課後班老師可協助告知事件背景，但不單獨致電家長
5
填寫事件記錄記錄時間、當時情境、孩子說的話、採取的行動

🟡 第二類：孩子疑似有身體傷害（疑似家暴）

1
觀察與記錄傷痕位置、描述不要詢問孩子「是不是被打」，避免二次傷害
2
若孩子主動說起：傾聽，不評斷
✓ 建議說法
「謝謝你告訴我，你很勇敢。老師會幫你找可以保護你的大人。」
3
立即通報輔導組或教務處依《兒童及少年福利與權益保障法》，知情者有通報義務，24小時內通報
4
由學校依規定通報地方主管機關（113保護專線）課後班老師不直接致電，由學校統一通報

🟢 第三類：孩子受傷（跌倒、碰撞）

1
評估傷勢輕微（擦傷）→ 校護處理 + 通知家長；嚴重（骨折、頭部撞擊、意識不清）→ 撥打119並立刻通知家長
2
通知導師與教務處
3
填寫意外事件記錄表包括時間、地點、發生經過、處理方式、家長聯繫記錄
📋 通報聯絡一覽：緊急醫療 119｜保護專線 113｜警察 110｜學校輔導組（依各校分機）
課後班老師的核心原則：察覺 → 記錄 → 通報 → 等待專業處理，不需獨力承擔。
